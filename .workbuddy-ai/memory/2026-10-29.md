# 2026-10-29

## AI background removal: ORT 404 on GitHub Pages + unselectable error text

User report (Brave, AMD GPU, live site): Balanced 512 failed with
`Failed to fetch dynamically imported module: …/assets/ort-wasm-simd-threaded.jsep.mjs`
(404) on WebGPU and `previous call to 'initWasm()' failed.` on the CPU retry.

### Root cause 1 — ORT runtime paths
`ort.env.wasm.wasmPaths` was set to a **directory prefix** derived from a
`?url`-imported `.wasm`. ORT resolves the ESM glue (`…jsep.mjs`, hardcoded
filename) and the `.wasm` payload as **two separate URLs**; Vite emits
content-hashed names, so the unhashed `.mjs` never existed in `docs/` → 404.
Fix in `model-loader.ts`: import both `ort-wasm-simd-threaded.jsep.mjs?url` and
`…jsep.wasm?url` and use the **object form**
`wasmPaths = { mjs, wasm }` (supported by onnxruntime-web ≥1.19; the 1.31-dev
source reads `wasmPaths?.mjs` / `?.wasm`). Only the `jsep` pair is needed — the
default entry point IS the JSEP build. Dropped the jspi/asyncify/plain imports:
`docs/` went 86 MB → 30 MB.

### Root cause 2 — nothing in a dialog could be selected
Not CSS. `EditorCanvas` re-took focus on `focusout`/`click` by focusing the
offscreen paste-catcher textarea; focusing it **collapses the document
selection**. Any click on non-focusable dialog content (the error text) dropped
focus to `<body>` → refocus → selection gone. Diagnosed by dragging a selection
over the rendered error block and tracing `mousedown`/`selectstart`/
`selectionchange` (selectstart fired, unprevented, then `len: 0`).
Fix: `EditorCanvas` records the pointerdown origin and stands down while the
gesture belongs to an open `.m-dialog`.

Also: `.ai-error` is now explicitly `user-select: text`, wraps long URLs
(`overflow-wrap: anywhere`, `min-width: 0` on the flex child) and carries a
Copy button.

### Probe
`scripts/ai_ort_assets_probe.mjs` — serves `build/` at `/paint.svelte/`, builds
a tiny Identity ONNX graph with `onnx-proto`, runs a real ORT session against
the emitted assets, then drives the dialog (File→New, paint a stroke, AI
Models→Remove Background, HF blocked) and asserts selection + copy. All PASS.

Gotchas found: `onnx-proto` is CJS (default-import it); a prerendered
`src/routes/+layout.ts` is required for `npm run build` to emit `index.html`
(export.ps1 writes/removes it); puppeteer probes must run **in the background**
(foreground runs get SIGTERM'd); the sandbox's safe-delete shim fails to trash
an existing `build/` → `rm -rf build` first.

`npm run check`: 1 error (pre-existing `DocScene.ts` ticker typing, not mine),
54 warnings = baseline.
